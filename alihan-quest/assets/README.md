## Правила стиля

- Glossy 2.5D / 3D, как Clash Royale
- Бренд-символ: **вершина горы + сияние цели** (не корона)
- Фон у исходников убран → прозрачный PNG
- Без логотипов Marvel / лиц героев на сундуках

## Подключение в игру

Пока ассеты лежат отдельно. Подключать через пути вида:

`assets/icons/01-navigation/nav-home.png`
